# Имитационная модель селективности токовых защит РТ-81/1

## 📌 О проекте

Имитационная модель для исследования селективности смежных токовых защит с зависимой выдержкой времени в городских кабельных сетях 6 кВ. Модель позволяет анализировать влияние расстояния до места короткого замыкания и насыщения трансформаторов тока на работу индукционных реле РТ-81/1.

Проект разработан в рамках производственной практики (НИР) в ЮУрГУ.

## 🎯 Задачи

- Разработать математическую модель блока «кабельная линия — трансформатор тока — реле РТ-81/1»
- Реализовать имитационную модель на Python с графическим интерфейсом
- Провести экспериментальные исследования селективности защит
- Оценить влияние насыщения трансформаторов тока на время срабатывания

## 🧠 Математическая модель

### Времятоковая характеристика реле РТ-81/1

t = 1 / (20 * ((k - 1) / 6) ** 1.8) + t_уст

где k = I / I_уст — кратность тока.

### Насыщение трансформатора тока

При превышении тока начала насыщения вторичный ток снижается по нелинейному закону с погрешностью до 40%.

## 🖥 Функциональность

- Задание расстояния до КЗ (0–100%)
- Выбор вида КЗ (3-фазное / 2-фазное)
- Настройка параметров ТТ и уставок реле
- Пошаговая имитация работы реле
- 4 графика в реальном времени
- Журнал событий
- Сохранение параметров и графиков

## 📊 Результаты

- Селективность обеспечивается только с **85% длины линии**
- Насыщение ТТ замедляет реакцию защиты в **2–2,5 раза**
- При I_нас < 7 А защита может **не сработать**
- Модель верифицирована с расхождением **< 0,08%** с теорией
